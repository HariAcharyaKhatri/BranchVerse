# BranchVerse — Fantasy Visual Asset Attribution & License Registry

This document records the origin, author, license, and usage terms for all visual and audio assets integrated into the BranchVerse interactive storytelling platform.

All assets utilized in BranchVerse adhere strictly to permissive open licenses (**CC0 1.0 Universal / Public Domain**, **CC-BY 3.0**, or **CC-BY 4.0**).
